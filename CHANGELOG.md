## 0.2.0

### Features

- Add a changelog and a release workflow built on the reusable workflows in `reusable-workflows-library`

### Changes

- Rename the marketplace to `outoforbitdev` and the plugin to `agentic-coding-library` (previously `personal-workflow`). Skills are now invoked as `/agentic-coding-library:<skill>`. Reinstall with `/plugin install agentic-coding-library@outoforbitdev`

## 0.1.0

### Features

- Scaffold the plugin marketplace with the `personal-workflow` plugin
- Add the `pull-issue` skill, which saves a GitHub issue locally as Markdown
- Add the `pr-template` skill, which finds and follows a repo's PR template
